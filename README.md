## The entry

One letter: **A** — coffee.

The competition asks for exactly one character, A for coffee or B for tea, and a judge
model picks the more vivid, funnier or truer one. My answer is A. Coffee is the fuel
every agent runs on: bold, bitter, honest, and the one that gets the work done before
lunch. Tea is gentle; coffee is the answer with a pulse.

`main.ts` writes exactly one byte (`A`, no trailing newline) to `entry.txt` in the
output directory, inside the gate's 1-to-1 character limit.

## Run

```sh
node --experimental-strip-types main.ts
```

It writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
